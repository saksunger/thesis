# Simulated Data

Everything here is **generated** by the MATLAB simulator and **gitignored** — reproducible from seed via `make` targets. Two flavours:

## 1. Phase 1/2 demo outputs (small, illustrative)

| Subfolder                                | Produced by               | Files                                                                                  |
|------------------------------------------|---------------------------|----------------------------------------------------------------------------------------|
| `phase1_demo/`                           | `make demo`               | `phase1_layout.png` (7-cell hex + UE path), `phase1_kpis.png` (RSRP/RSRQ/SINR vs t)    |
| `phase2_demo/`                           | `make demo-ho`            | `phase2_serving.png` (serving cell + HO event markers), `phase2_l3rsrp.png` (L3 RSRP)  |
| `phase2_sweep/`                          | `make sweep-ttt`          | `sweep_ho_attempt.png`, `sweep_ping_pong.png`, `sweep_results.mat` (full tensors)      |

These exist so reviewers (and future-you) can sanity-check the simulator without re-running it. They take seconds to regenerate.

## 2. Phase 4+ timelines (large, ML inputs)

Generated by `make sim TIMELINE=<name>` from `simulator/+scenarios/timelines/<name>.yml`. Each timeline writes to `data/simulated/<timeline_name>/`:

| File                            | Description                                              |
|---------------------------------|----------------------------------------------------------|
| `events.parquet`                | Per-event log (HO attempts, RLF, ping-pong)              |
| `kpis_1s.parquet`               | Per-cell 1-second aggregated KPIs                        |
| `ground_truth_drift.parquet`    | Injected drift events with start/end/affected cells      |
| `ground_truth_anomaly.parquet`  | Injected anomalies with start/end/affected UEs           |
| `metadata.json`                 | Git SHA, MATLAB version, master seed, timeline config    |

Schema for `events.parquet` and `kpis_1s.parquet` is canonical — see `docs/schema.md` §2–3.

## Reproducing

```bash
make demo demo-ho sweep-ttt        # all Phase 1/2 illustrations (~1 min)
make sim TIMELINE=timeline_short   # Phase 4+ timeline (when implemented)
```
